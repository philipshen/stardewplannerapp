# Stardew Planner

An iOS, Android and web farm planner for Stardew Valley, built with React Native (Expo SDK 57). Everything runs on the device; there is no backend.

## Features

- **Named saves.** Create, rename, duplicate and delete farm plans. Plans autosave on the device, and each save card shows a live thumbnail.
- **8 farm layouts** (Standard, Riverland, Forest, Hill-top, Wilderness, Four Corners, Beach, Meadowlands) and **6 interiors** (Greenhouse, Shed, Big Shed, Farmhouse, Cellar, Cabin), each with seasonal terrain.
- **447 placeable items**: buildings, crops, fruit and wild trees, sprinklers, scarecrows, machines, storage, fences (auto-connecting), floors and paths, lighting, decor, rarecrows and furniture (rugs, beds, tables, wall decor and more).
- **A searchable item index of 1,390 items**: fish, minerals, artifacts, cooking, artisan goods, forage, tools, weapons, rings, hats, boots, trinkets, books, animals and more. It has category and subcategory filters, ranked fuzzy search, and detail pages with prices, seasons, sources and linked recipe ingredients.
- **Mobile-first editing.** Tools: Pan, Place, Erase, Select. Shapes: brush, area fill and outline. Pinch or two-finger drag zooms and pans in any tool. Long-press selects; you can box-select and move groups, duplicate, and undo/redo.
- **Coverage overlays** for sprinklers, scarecrows, Junimo Huts and Bee Houses (flower range). Fruit trees that lack the 8 clear tiles they need get a warning.
- **Farm summary**: item counts, estimated cost, total crafting and building materials, and how many crops are watered and protected from crows.
- **Export** a plan as a PNG image or a `.stardewplan.json` file, and import it again on any device.
- The web version also has a hover ghost preview, mouse-wheel zoom and keyboard shortcuts (`Ctrl/Cmd+Z`, `Ctrl+Y`, `Del`, `H`/`P`/`E`/`V` to switch tools, `/` to open the item picker).

## Run it

```bash
npm install
npx expo start          # then press i (iOS), a (Android) or w (web)
```

This app uses native modules (Skia, Reanimated, Gesture Handler), so on a phone you need a development build:
`npx expo run:ios` or `npx expo run:android`, or build with EAS (`npx eas-cli@latest build --profile development`).

## Project layout

```
src/app/            Expo Router screens (home & saves, planner, item index, about)
src/planner/        Skia canvas, gestures/tools, model (placement rules, coverage, stats), panels
src/store/          zustand stores: saves (AsyncStorage) and editor session (undo/redo)
src/data/           item index + search, maps; generated/ holds build outputs
scripts/            data + art generators
  build-data.ts     merges the item dataset with the curated furniture/decor list
  gen-art.ts        procedural pixel art: icons, world sprites, farm maps, app icon
  art/              pixel raster lib, palettes, item painters, map layouts, UI glyphs
```

To regenerate data and art after editing the scripts, run `npm run gen`.

## Data & art

- Item facts (names, prices, seasons, recipes) come from the MIT-licensed [`stardew-valley-data`](https://www.npmjs.com/package/stardew-valley-data) package, plus a hand-curated furniture and decor list in `scripts/supplemental.ts`. Item descriptions are generated from those facts.
- **All artwork is original procedural pixel art** generated by `scripts/gen-art.ts`. No game sprites or assets are included. Farm layouts are planning approximations, not copies of the game's maps.
